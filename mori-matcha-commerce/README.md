# Mori Matcha 商城

这是一个抹茶商品网站和独立的商家后台。顾客在首页看商品、选规格、加入购物袋；有权限的管理员在后台改商品、处理体验订单、维护库存等。

**先看这里：** [商家使用说明](docs/使用说明.md)。开发人员要对接后端时再看 [接口与部署说明](docs/API.md)。

## 打开哪个地址

| 要做的事 | 地址 |
| --- | --- |
| 看商城 | [已发布的私人预览](https://mori-matcha-commerce-jie.geniallily16.chatgpt.site/) |
| 进入商家后台 | [预览站的管理员登录页](https://mori-matcha-commerce-jie.geniallily16.chatgpt.site/admin/login) |
| 看项目代码 | 当前目录 mori-matcha-commerce/ |

预览站是私有的，需要先获得该站访问权限。商城页面不展示商家后台入口；管理员直接打开 /admin/login，使用已授权的 ChatGPT 账号登录。第一次绑定主管理员还需要交付时提供的激活码，**不要把激活码放进公开仓库**。

## 最常做的事

1. 登录后台，进入 **商品管理**，点“编辑商品”。
2. 改“商品名称”“中文商品介绍”“售价 (RM)”，在“商品主图与轮播图”或“商品详情介绍图”上传、替换图片。
3. 点击“保存商品”，再刷新商城首页确认展示。已有规格的库存请到 **库存管理** 调整。

详细步骤、后台所有模块及常见问题见 [商家使用说明](docs/使用说明.md)。

## 当前能用到什么程度

商品、图片、库存、体验订单和后台设置通过服务端接口保存。管理员权限在服务端检查；普通登录账号无法进入后台。当前订单是**体验订单**：不会真实收款、退款、向快递公司下单，也没有接通短信邮件、发票与税费。报表中的体验订单金额不是实际营业收入。正式营业前必须接通并验证这些外部服务。

这个 GitHub 仓库存放**源码**；上传代码本身不会自动更新已经发布的预览站，也不会自动部署到另一台服务器。部署所需的身份认证、数据库、图片存储和服务端环境变量见 [接口与部署说明](docs/API.md)。
