# Mori Matcha 使用说明

前台沿用原网页的抹茶配色、背景与商品照片；增加贵州铜仁茶叶介绍，以及跟随鼠标的茶叶与抹茶粉粒子。页面使用原生滚动，支持减少动态效果偏好；触摸设备关闭鼠标粒子。

前台没有商家按钮、商家菜单或管理快捷入口。管理员直接访问 `/admin`，未登录或无管理权限时不能进入工作台。当前使用 ChatGPT 账号登录，首次主管理员用本次交付的激活码绑定；激活码仅在服务端配置，不在网页源码中保存。

## 第一次使用

1. 打开交付的后台地址，使用自己的 ChatGPT 账号登录。
2. 首次输入交付的管理员激活码。绑定成功后会初始化示例商品、分类、运费与店铺介绍。之后该账号直接进入后台。
3. 进入商品管理，点击编辑。修改商品名称、介绍、价格，上传或替换主图和商品详情介绍图；可以增加或停用规格、上下架商品。
4. 已有 SKU 的库存到库存管理调整；填正数入库、负数出库，并填写原因。
5. 去前台刷新，查看保存后的商品；可填写测试信息创建体验订单，再到后台验证处理流程。

## 本版功能

| 模块 | 当前可操作内容 |
| --- | --- |
| 商品 | 中文 / 英文名称和介绍、主图与多图、详情介绍图、分类、价格、规格、上下架、草稿 |
| 库存 | SKU 库存、调整原因、手动流水；下单占用、取消归还、库存不足回滚 |
| 订单 | 查询、搜索、状态筛选、详情、内部备注、演示确认、测试运单、测试完成、取消 |
| 售后 | 顾客申请、后台审核、处理说明、顾客查看进度；不触发真实退款 |
| 客户 | 下单客户列表、标签、内部备注、账号限制下单 |
| 优惠 | 优惠码、固定减免、使用门槛、到期时间、启停；结算和服务端下单复核 |
| 配送 | 马来西亚配送方案、运费、免运费门槛、启停 |
| 内容 | 首页介绍文字与图片、顶部公告、联系方式、售后与隐私说明 |
| 评价 | 已完成订单评价、后台审核、公开审核通过的评价 |
| 客服 | 顾客留言、后台回复、关闭工单、顾客查看回复 |
| 报表 | 体验订单汇总、订单明细、CSV 导出；不会把演示金额算作真实营收 |
| 权限 | 主管理员、运营主管、商品运营、客服、财务；服务端逐次鉴权 |
| 日志 | 商品、库存、订单、售后、人员等关键操作记录 |
| 前台 | 中 / 英 / 马来文导航、商品筛选与搜索、收藏、多规格、购物袋、测试结算、本人订单、收货地址保存 |

多语言商品字段目前为中文与英文，马来文界面的商品使用英文介绍。金额沿用原页面的 RM（MYR）。价格、库存及包装信息均需换成你的实际商品信息。

## 员工使用

员工先访问后台登录页并登录，展开“员工授权信息”，把自己的账号 ID 提供给主管理员。主管理员在“员工权限”新增该账号，并分配角色、启用账号。当前交付为私有预览；员工还需单独获得本站访问权限。普通消费者没有管理权限。

## 外部服务边界

当前数据能够持久保存，商品和业务表单使用实际 API，并非切换面板的静态演示。此版后端运行在 Sites 支持的环境，尚未实现 Java + Spring Boot + MySQL；接口约定见同目录 API.md。

在线支付、实际退款、物流下单及轨迹、短信邮件、税费与发票均未接通。后台会明确标记体验环境及服务状态。订单演示确认不产生真实付款，售后审核不产生真实退款，填写运单不向快递公司下单。

## 验证

已运行 TypeScript 检查、生产构建，以及基于实际业务控制器和事务 SQLite 适配器的集成检查：管理员隔离、首次绑定、商品修改、库存事务、服务端计价、优惠码、下单幂等、订单归属、超库存拒绝、库存归还、订单状态、售后、评价审核、工单回复、员工权限、CSRF、下架商品隐藏。

浏览器检查了首页、购物袋、分类筛选、规格详情及未授权访问后台跳转登录。管理员浏览器操作与实际上传存储需在首次管理员激活后验收；真实支付和真实物流未做端到端测试。
