# Mori Matcha 商家使用说明

这份说明给店主和员工看，按页面上的按钮操作即可。技术人员对接服务器时看 [接口与部署说明](API.md)。

## 先弄清楚两个页面

| 页面 | 用来做什么 | 谁能进入 |
| --- | --- | --- |
| [商城首页](https://mori-matcha-commerce-jie.geniallily16.chatgpt.site/) | 浏览商品、选规格、体验结算、查看自己的订单 | 获得预览站访问权限的访客 |
| [商家后台登录页](https://mori-matcha-commerce-jie.geniallily16.chatgpt.site/admin/login) | 改商品、调库存、处理订单、管理员工 | 获得预览站访问权限，且账号被授予后台角色的人 |

商城页面没有“商家后台”按钮或商家信息入口。请保存后台登录页链接，直接打开。当前发布的是**私有预览**，站点访问权限和商家后台权限是两层不同的权限。

## 第一次进入后台

1. 打开上面的“商家后台登录页”，点击“使用 ChatGPT 账号登录”。
2. **首次主管理员**输入交付时单独提供的激活码，点击“激活并进入工作台”。激活码不是 ChatGPT 密码。一个站点只能先绑定一个主管理员账号。
3. 以后用同一个账号登录，会直接进入后台，不需要再次输入激活码。
4. 如果你是员工，先登录后台页，展开“员工授权信息”，复制自己的**账号 ID** 给主管理员。主管理员在“员工权限”添加该 ID、邮箱、名称和角色并启用。私有预览站的访问权限仍需另外开通。

没有权限时会回到登录页。换错账号可点“切换账号”。不要在公开仓库、截图或聊天群公开激活码。

## 修改商品名称、价格和图片

1. 后台左侧点 **商品管理**，找到商品，点 **编辑商品**；要新建商品则点 **新增商品**。
2. 在“商品名称”填写中文名称；按需填写“英文名称”“中文商品介绍”“英文商品介绍”、产地、配料和储存方式。
3. 在“商品主图与轮播图”点 **上传图片**。第一张为首图；可移除旧图，或把其他图设为首图。“商品详情介绍图”里同样可上传、移除介绍长图。也可填写 HTTPS 图片地址并点“添加”。
4. 在“商品规格 / SKU”填写规格名称，例如 50g，以及 **售价 (RM)**，例如输入 18.90 表示 RM 18.90。可增加规格或停用规格。
5. 选择“草稿 / 上架 / 下架”，点 **保存商品**。上架前至少启用一个规格；保存后刷新商城查看结果。

图片支持 PNG、JPG、WebP、GIF，单张不超过 5 MB。最多 12 张主图、20 张详情图；保存商品至少要有一张主图和一个价格大于 0 的规格。新商品可填写初始库存；**已有规格的库存输入框只读**，请用“库存管理”调整。下架商品不会在商城列表出售；已产生的历史订单不会因此删除。

### 调整库存

在 **库存管理** 找到商品规格，点“调整库存”，填写变动数量和原因。正数是入库，负数是出库；页面会记录人工调整流水。体验订单创建时会扣减库存，符合条件的订单取消后归还库存。不要通过改商品资料来覆盖已有规格库存。

### 改首页介绍

在 **首页介绍** 编辑标题、介绍文字和首页商品介绍图，并决定是否显示；在 **店铺设置** 编辑店铺名称、公告、客服联系方式、售后政策和隐私说明。改完刷新商城核对。商品详情图在“商品管理”，首页介绍图在“首页介绍”，两者位置不同。

## 处理体验订单

顾客在商城登录后可添加购物袋、选择马来西亚配送方案、使用优惠码并提交**体验订单**。后台在 **订单管理** 可搜索、筛选，点“查看详情”检查商品、地址、金额和内部备注。

| 当前状态 | 后台可做的事 | 实际含义 |
| --- | --- | --- |
| 待付款 | 演示确认、取消、写内部备注 | 演示确认只把订单推进到待发货，没有真实支付 |
| 待发货 | 填写承运商和运单号、取消、写备注 | 填运单仅记录测试信息，不向快递公司下单 |
| 已发货 | 标记完成、写备注 | 没有物流接口或真实配送轨迹 |
| 已完成 / 已取消 | 查看与备注 | 售后在“售后管理”处理，不会自动退款 |

顾客只能查看自己的订单；待付款订单可自行取消，其他符合条件的订单可申请售后。后台 **售后管理** 审核并回复，顾客可看处理结果。审核通过**不会把钱退回去**，因为目前根本没有真实收款。

## 后台各栏目速查

| 栏目 | 目前可做的事 |
| --- | --- |
| 经营概览 | 看体验订单、待办、在售商品和库存提醒 |
| 商品管理、商品分类 | 改名称、文字、主图、详情图、规格、价格、上下架；维护分类 |
| 库存管理 | 按规格加减库存，查看人工调整记录 |
| 订单管理、售后管理 | 处理体验订单、内部备注、售后审核与回复 |
| 客户管理 | 查看下单客户，添加标签和内部备注，限制下单 |
| 优惠营销、配送运费 | 设置优惠码、金额和门槛；设置马来西亚运费与免运费门槛 |
| 首页介绍、店铺设置 | 调整首页内容、公告、联系方式和政策 |
| 评价审核、客服工单 | 审核已完成订单的评价，回复顾客留言 |
| 财务报表 | 看体验订单统计，下载 CSV；真实收款始终为 0 |
| 员工权限、操作日志 | 给员工分配角色或停用账号；查看关键操作记录 |

不同角色看到的栏目不同。主管理员可管理全部模块和员工；运营主管管理日常业务；商品运营主要管理商品、分类、库存、营销、内容与评价；客服管理订单、售后、客户与留言；财务只可看订单、加备注、审核售后并看报表与日志，不能发货或演示确认。

## 开始正式卖货前

本版已经有可保存的商品、图片、库存、设置和体验订单，但**不是已接通支付的正式商城**。请先核对实际商品名称、价格、规格、包装、配料、产地、图片、政策与运费。再由开发人员接通并测试真实支付与退款、物流、通知、税费发票，以及生产环境的备份和监控。当前仅支持马来西亚地址与 MYR 价格；界面有中文、英文和马来文导航，商品资料由后台维护中文与英文，马来文界面使用英文商品介绍。

## 常见问题

**改了商品，前台没变？** 确认点过“保存商品”，商品处于“上架”、至少有一个启用规格，然后刷新商城。新商品还要选有效分类。

**图片传不上去？** 检查格式和 5 MB 大小限制；若提示图片存储未配置，需要部署人员配置图片存储。上传成功后仍需点“保存商品”。

**已经登录，为什么进不了后台？** 登录只证明账号身份。还需要主管理员在“员工权限”授权该账号 ID；在私有预览中还需要站点访问权限。

**为什么报表金额不是真实营业额？** 所有订单都是体验订单，没有支付通道。报表显示流程数据，真实收款为 0。

**代码上传 GitHub 后，网站会自动更新吗？** 不会。仓库放源码，当前预览站由单独的发布流程维护。
